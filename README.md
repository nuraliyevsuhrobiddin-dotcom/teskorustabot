# TeskorUsta24 Telegram Bot

Admin bilan bog'lanish, muammo yuborish va ustalarni ro'yxatga olish uchun Telegram bot.

## Ishga tushirish

1. Paketlarni o'rnating:

```bash
npm install
```

2. `.env.example` fayldan `.env` yarating:

```bash
cp .env.example .env
```

Windows PowerShell:

```powershell
Copy-Item .env.example .env
```

3. `.env` ichiga bot tokeningizni yozing:

```env
BOT_TOKEN=PASTE_YOUR_TELEGRAM_BOT_TOKEN_HERE
ADMIN_ID=123456789
CHANNEL_ID=@your_channel_username
CHANNEL_URL=https://t.me/your_channel_username
SITE_URL=https://teskorusta24.uz
SUPABASE_URL=
SUPABASE_SERVICE_ROLE_KEY=
```

4. Botni ishga tushiring:

```bash
npm start
```

Development rejimida:

```bash
npm run dev
```

## Supabase

Bot `SUPABASE_URL` va `SUPABASE_SERVICE_ROLE_KEY` berilsa Supabase ishlatadi. Bu qiymatlar bo'sh bo'lsa, eski `data/db.json` fayl fallback sifatida ishlaydi.

Supabase SQL editorida quyidagilarni yarating:

```sql
create table if not exists users (
  id bigint primary key,
  first_name text default '',
  username text default '',
  updated_at timestamptz default now()
);

create table if not exists masters (
  id bigint generated by default as identity primary key,
  status text not null default 'pending',
  user_id bigint not null,
  username text default '',
  data jsonb not null default '{}'::jsonb,
  created_at timestamptz default now(),
  updated_at timestamptz
);

create table if not exists orders (
  id bigint generated by default as identity primary key,
  status text not null default 'new',
  user_id bigint not null,
  username text default '',
  data jsonb not null default '{}'::jsonb,
  created_at timestamptz default now(),
  updated_at timestamptz
);
```

`SUPABASE_SERVICE_ROLE_KEY` serverda saqlanishi kerak. Uni client yoki public saytga qo'ymang.

## Bot funksiyalari

- `/start` va `/menu` orqali chiroyli inline menu.
- Kanalga majburiy obuna tekshiruvi.
- `Usta chaqirish` flow:
  - xizmat turi
  - region
  - tuman/shahar
  - vaqt
  - telefon
  - muammo matni
  - ixtiyoriy rasm/video
- `Shoshilinch chaqiruv` flow.
- `Usta bo'lish` flow:
  - ism
  - telefon
  - xizmat turi
  - region
  - tuman/shahar
  - kanal e'loni uchun ixtiyoriy rasm
- Telefon raqam validatsiyasi.
- Admin bilan bog'lanish.
- Muammo yozish.
- Admin panel:
  - kanalga e'lon joylash
  - broadcast
  - statistika
  - buyurtma statuslarini yangilash
- Har bir user uchun alohida step-by-step state.
- Xatoliklar `console.error` orqali log qilinadi.
